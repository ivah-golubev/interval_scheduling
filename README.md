# Расписание: interval scheduling
Вариант 26

Занятия проводятся в аудиториях по парам. Иногда заявок на одну аудиторию
больше, чем доступных слотов. Какой максимум занятий можно провести без
накладок?

Анализ следующих характеристик:
- загрузка аудиторий по часам
- популярные курсы
- незагруженные аудитории

Графики:
- количество занятий по дням
- длительность занятий
- загрузка по часам и по аудиториям
